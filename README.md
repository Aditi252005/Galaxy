Galaxy Windows And Modulars

A full-stack business website developed for Galaxy Modulars, a company specializing in modular windows and doors. The website showcases products, enables customers to send enquiries, allows job applicants to upload resumes, and provides a modern, responsive user experience.

🚀 Features

• Modern and responsive user interface built with React

• Product catalog with dedicated product pages

• Customer enquiry form with backend validation

• Career page with resume upload functionality

• Automated email notifications using Resend

• Mobile-friendly design

• SEO-optimized pages for improved search visibility

• Production deployment with a custom domain


🛠 Tech Stack


Frontend

• React.js

• React Router

• CSS3,VITE


Backend
• Node.js

• Express.js

• Multer (File Uploads)

• Resend API (Email Service)
